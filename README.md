# CI/CD Landing Page

Landing page portfolio sederhana untuk tugas implementasi CI/CD menggunakan GitHub Actions dan DigitalOcean.

## Struktur folder

- `index.html` — halaman utama website
- `assets/` — gambar dan aset tambahan
- `css/` — file desain website
- `js/` — file interaksi website

## Menjalankan secara lokal

Buka folder proyek menggunakan Visual Studio Code, lalu buka `index.html` di browser. Untuk pengalaman lebih nyaman, gunakan ekstensi Live Server.
